### Project Overview
I am building a sketching tool that recognizes user drawings and renders a stylized version in near real time. The aim is to combine recognition with creative rendering, producing “clean” results from rough input.

### Technical Approach
- **Sketch classification** for fast recognition (QuickDraw‑style).
- **Stylization pipeline** for shape‑preserving output.
- **Latency‑aware** inference so the UI feels immediate.
